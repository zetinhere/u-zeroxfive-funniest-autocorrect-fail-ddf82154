One line, 50 characters: a plain domestic text where autocorrect swaps one
word and dinner turns horrifying.

> Don't forget to defrost the children before dinner

`main.py` scores six candidate lines against the judge's published brief
(on-subject first, then the laugh on first read, the real-slip feel, the
clean one-liner, and the freshness of the wrong word) and writes the winner
to `/output/entry.txt`. Deterministic: no network, no input, no randomness.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (no trailing newline, so the file
is exactly the one line the gate measures).
